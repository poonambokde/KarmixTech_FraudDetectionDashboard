# Fraud Detection & Risk Analytics Dashboard

## 📌 Business Problem
How can a financial institution detect fraudulent transactions 
and assess risk exposure before significant losses occur?

## 📊 Dataset
Credit Card Fraud Detection Dataset (Kaggle)
- 284,807 transactions
- 492 fraud cases (0.17% fraud rate)
- Source: kaggle.com/datasets/mlg-ulb/creditcardfraud

## 🛠️ Tools Used
- Python (Pandas, Matplotlib, Seaborn) - EDA
- Power BI - Dashboard & DAX Measures

## 🔍 Key Insights
- 73.6% of fraud occurs in Low Risk (small amount) transactions
- Peak fraud hours: 2 AM (57 cases) and 11 AM (53 cases)
- Fraud rate is only 0.17% - highly imbalanced dataset

## 💡 Recommendations
- Implement real-time alerts during peak fraud hours
- Monitor small-amount transactions closely for fraud patterns
